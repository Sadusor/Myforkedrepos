# My Forked Repositories — Sadusor

A categorized, linked inventory of repositories visible in the connected GitHub account, checked **2026-10-09**. Every listed fork was checked against GitHub's `fork` flag and upstream parent. Summaries are based on repository descriptions; they are **not** code audits, security endorsements, or claims that ORION has integrated a donor.

## How to use this catalog

Browse a category, open the fork, and follow the upstream reference for the original project. For ORION donor decisions, verify the current source revision, license, relevant implementation, dependencies, and Windows compatibility **before** adopting code. A fork is a candidate, not a proven ORION module.

## Scope and maintenance

This is a snapshot of the repositories returned by the connected GitHub account at the time of the audit, not a continuously synchronized inventory. Newly forked or deleted repositories require a refresh. Category assignments are practical navigation aids; some projects fit more than one category.
